This is a README file accompanying a practical at University of Regensburg chair of Theoretical Ecology. The goal was to investigate if matching a Deep Neural Networks' loss function to the datas distribution increases predictive performance or model inference.

This Repository is divided into three subfolders: 
- code/ : which contains all code for data generation, analysis as well as previously generated data as .csv-files for re-analysis.
- images/ : which contains all figures used in the final report.
- writing/ : which contains the final report as .pdf, .odt as well as the used bibliography as .bib. 
- logs/ : which contains logs from the runs, as well as data saved from re-analysis.
